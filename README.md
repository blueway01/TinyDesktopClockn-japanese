# TinyDesktopClockn 日本語版 — 時計＋Wi-Fi実測メーター

Windows用の小さなデスクトップ時計です。設定画面・メニュー・状態表示は日本語です。MITライセンスのオープンソースとして利用・改変・再配布できます。

## 動作環境と起動

- Windowsのデスクトップ環境と .NET Framework 4.x が必要です。
- 下記の手順でビルドし、`dist\TinyDesktopClockn.exe` を実行してください。インストーラーは不要です。
- 管理者権限、APIキー、追加のNuGetパッケージは不要です。
- スタートアップ登録は任意です。設定画面から有効にした場合だけ登録します。

`dist\TinyDesktopClockn.exe` は時計とWi-Fi通信速度を一つの小型ウィンドウに表示します。既存の `TinyDesktopClock` とは別アプリとして動作し、設定・自動起動登録・二重起動判定は独立しています。

## 表示

- 上段：時刻と日付
- 下段：細い横方向のダウンロード（↓）・アップロード（↑）メーター、現在の実測 Mbps、起動中の最高 Mbps
- メーターの色：緑→黄→橙→赤。速度に応じて表示レンジを自動調整します。

通信速度は、現在稼働中のWi-Fiアダプターの受信・送信バイト数を約1秒ごとに比較して求めます。測定サーバーへ通信する速度テストではありません。Wi-Fi未接続や取得エラー時は日本語の状態を表示します。

受信・送信の最高値は有効な測定値が出るたびに更新し、アプリを終了するまで固定表示します。アプリを再起動すると最高値は0から測定し直します。

初期サイズは250×112ピクセルです。最小サイズは210×96ピクセルで、従来どおりドラッグで位置とサイズを変更できます。

## 操作

- 時計の中央を左ドラッグ：移動
- 時計の端をドラッグ：サイズ変更
- 右クリック：設定、表示位置、終了
- ダブルクリックまたはF2：設定画面
- 通知領域の時計アイコンをダブルクリック：前面へ復帰しクリック透過を解除

設定は `%APPDATA%\TinyDesktopClockn\settings.json` に保存します。自動起動は設定で選んだときだけ現在のユーザーへ登録します。

## ビルド・検証

Windows標準の .NET Framework C# コンパイラでビルドします。追加パッケージは不要です。

```powershell
& '.\build.ps1'
& '.\dist\TinyDesktopClockn.exe' --self-test
& '.\test-integration.ps1'
```

EXEと画面プレビューは `dist` フォルダーに保存されます。`--smoke-test` は起動と設定画面のプレビューを生成し、自動で終了します。

PowerShellでこのフォルダーを開いて実行してください。`--self-test` と統合テストでは、時刻表示、設定の保存・復元、日本語パス、通信量と最高値の計算などを確認します。統合テストのログは `test-output\integration-result.txt` に出力します。

## プライバシー

通信速度はOSのネットワーク統計から計算します。測定用の外部サーバーへの送信は行いません。設定とエラーログはローカルに保存されます。設定ファイル・ログ・ビルド生成物はリポジトリに含めません。
